# 大肥鱼内置模块 · QQ 互通

本模块派生自 [Yuuyuko-uu/dsh-qq-link](https://github.com/Yuuyuko-uu/dsh-qq-link)，原作者 **Yuuyuko-uu**。RabbitStudio 在原实现上扩展功能并整合进大肥鱼；不代表原作者出品。完整原许可见 [LICENSE](LICENSE)。

本目录随大肥鱼统一构建、安装和更新，不独立发布。使用方法与正式发布状态见 [项目 README](../../README.md)，版本与完整功能清单见 [changelog-v0.7.3.json](../../update/changelog-v0.7.3.json)。

## 功能与边界

- 连接 OneBot HTTP 后端，支持 NapCat / SnowLuma；私聊、群聊各自独占绑定 DSH 会话，并登记工作区。
- 支持主人身份、逐会话沙箱授权、回复门槛、点名接听、消息合并、冷却、长回复拆段、角色与特殊设定。
- 支持图片和文件收发、额外归档、事件接收、戳一戳及语音转写；归档与附件分别管理，不执行收到的文件。
- 语音发送为独立状态入口，当前服务暂不可用。
- 支持共享表情素材库、原图 / GIF 回发、标签分类、语境发送与自动收藏。
- 支持主人账号操作、好友和群邀请审批、群历史查询及代发；能力分别受身份、配置及后端权限约束。
- 支持 QQ 空间发布、浏览、定时计划和互动配置；实际动作取决于后端与可用工具。
- 历史导入接受 OneBot 历史、QCE / OneBot JSON 和 QQ TXT，按时间分段、摘要衔接，支持暂停、重试和断点恢复。模型结果通过内置长期记忆接口写入，固定目标库，来源或隔离变化后要求重新确认。
- 配置、路由 `/dsh-qq-bridge/*`、来源登记和历史导入数据路径保持兼容。历史资料可供模型处理，不代表 QQ 云端历史完整。

## 群聊频率

在“QQ 互通 → 群聊频率”配置，数字失焦保存、开关即时保存。

每个群都有独立读取规则，从下拉框选择要配置的群。参数顶部的“启用读取间隔”默认开启；关闭后下方参数置灰，实时接收，不应用采样间隔、条数截断、概率和冷却限制，但保留原值供重新启用。旧共享参数在升级时一次性迁入各群，不再保留共享配置。回复门槛说明位于“消息策略”，门槛开关仍在“绑定”页按群配置。

- 未设置读取规则的群默认每 10 分钟采样最新 30 条尚未处理的消息，最多 100 条；合成一批，仅启动一轮。没有新消息不调用模型，超出上限的旧消息不排队补读。
- 点名必回复默认开启：@、引用机器人及点名关键词及时处理，跳过采样间隔、回复概率与冷却。关闭后，点名也遵循本群规则。主动回应关闭时仍只接收点名及获准的后续消息。
- 回复概率在启动模型前抽选；回复门槛在模型读取后判断，拒绝回复仍产生 token 用量。
- 读取间隔设为 0 可用实时模式，冷却、每分钟处理上限和单批合并上限均按群配置。既有全局概率与实时参数作为旧绑定的初始值保留。
- 采样进度持久保存，模型仍在处理时不叠加定时批次。开启点名必回复时继续本地轮询识别点名；关闭后在间隔内跳过该群历史请求。
- 回复本批最新消息时直接发送；回应较早话题时，模型通过 `qq_reply_target` 选择原消息 ID，插件只允许引用当前群、当前端点已读取的消息，首个文字分段携带引用。原消息正文附带 QQ 消息 ID；仅保留本次运行最近 300 个已读 ID，不跨重载恢复引用索引。实际引用展示取决于 OneBot 后端。
- 本策略限制新消息的进入频率和数量，不删除聊天存档，也不裁剪已有 DSH 会话上下文。减少 token 的实际比例取决于消息分布、点名次数和模型行为。
