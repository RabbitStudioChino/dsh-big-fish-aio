# 大肥鱼内置模块 · QQ 互通

本模块派生自 [Yuuyuko-uu/dsh-qq-link](https://github.com/Yuuyuko-uu/dsh-qq-link)，原作者 **Yuuyuko-uu**。RabbitStudio 在原实现上扩展功能并整合进大肥鱼；不代表原作者出品。完整原许可见 [LICENSE](LICENSE)。

本目录随大肥鱼统一构建、安装和更新，不独立发布。使用方法与正式发布状态见 [项目 README](../../README.md)，版本与完整功能清单见 [changelog-v0.7.3.json](../../update/changelog-v0.7.3.json)。

## 功能与边界

- 连接 OneBot HTTP 后端，支持 NapCat / SnowLuma；私聊、群聊各自独占绑定 DSH 会话，并登记工作区。
- 支持主人身份、逐会话沙箱授权、回复门槛、点名接听、消息合并、冷却、长回复拆段、角色与特殊设定。
- 支持图片和文件收发、额外归档、事件接收、戳一戳及语音转写；归档与附件分别管理，不执行收到的文件。
- 语音发送为独立状态入口，当前服务暂不可用。
- 支持共享表情素材库、原图 / GIF 回发、标签分类、语境发送与自动收藏。
- 支持主人账号操作、好友和群邀请审批、群历史查询及代发；能力分别受身份、配置及后端权限约束。
- 支持 QQ 空间发布、浏览、定时计划和互动配置；实际动作取决于后端与可用工具。
- 历史导入接受 OneBot 历史、QCE / OneBot JSON 和 QQ TXT，按时间分段、摘要衔接，支持暂停、重试和断点恢复。模型结果通过内置长期记忆接口写入，固定目标库，来源或隔离变化后要求重新确认。
- 配置、路由 `/dsh-qq-bridge/*`、来源登记和历史导入数据路径保持兼容。历史资料可供模型处理，不代表 QQ 云端历史完整。

## 验证

在本目录运行 `npm test`，或在项目根目录运行完整 `npm test`。模拟宿主与后端测试不等于真实 DSH、QQ 或模型服务验收。
