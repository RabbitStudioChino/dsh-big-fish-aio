# 大肥鱼内置模块 · 鱼的心情

本模块派生自 [Yuuyuko-uu/dsh-feiyu-mood](https://github.com/Yuuyuko-uu/dsh-feiyu-mood)，原作者 **Yuuyuko-uu**。RabbitStudio 在原实现上扩展功能并整合进大肥鱼；不代表原作者出品。完整原许可见 [LICENSE](LICENSE)。

本目录随大肥鱼统一构建、安装和更新，不独立发布。使用方法与正式发布状态见 [项目 README](../../README.md)，版本与完整功能清单见 [changelog-v0.7.3.json](../../update/changelog-v0.7.3.json)。

## 功能与边界

- 自动判断心情和七维情绪，支持模型、判定可信度、基线、下限、衰减和上下文注入策略。
- 默认跟随经核验的 QQ 记忆库归属，也支持自定义会话 / 工作区模式；重新绑定隔离状态，避免误继承其他范围的心情。
- 可按日期查看完整变化记录。挂饰可拖动、缩放、调节背景透明度及打开 / 收起数值卡片。
- 挂饰弹出卡片可选择今日心情、工作区今日开销或绑定范围内的随机记忆。
- 五档心情分别管理全身像和半身像，图片直接点击上传或恢复默认；校验 PNG、JPEG、GIF、WebP 签名与大小。
- 自定义图片按 SHA-256 内容命名及去重，多个位置共用一份文件，删除仅清理无引用图片。
- 上传预览提供图片轮廓提示、键盘与触屏入口，并适配减少动态效果；自定义图片实时同步挂饰。
- 保持 `/dsh-feiyu-mood/*`、原配置及用户图片数据路径兼容。模型判断会产生相应模型用量。

## 验证

在本目录运行 `npm test`，或在项目根目录运行完整 `npm test`。模拟宿主与后端测试不等于真实 DSH、QQ 或模型服务验收。
