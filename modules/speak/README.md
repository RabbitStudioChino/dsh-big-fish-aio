# 大肥鱼内置模块 · 主动搭话

本模块派生自 [Yuuyuko-uu/dsh-speak-up](https://github.com/Yuuyuko-uu/dsh-speak-up)，原作者 **Yuuyuko-uu**。RabbitStudio 在原实现上扩展功能并整合进大肥鱼；不代表原作者出品。完整原许可见 [LICENSE](LICENSE)。

本目录随大肥鱼统一构建、安装和更新，不独立发布。使用方法与正式发布状态见 [项目 README](../../README.md)，版本与完整功能清单见 [changelog-v0.7.3.json](../../update/changelog-v0.7.3.json)。

## 功能与边界

- 对 QQ 绑定工作区内选中的活跃会话，按间隔与峰谷命中线尝试主动搭话，复用会话人格、历史、工具和记忆。
- 支持安静时段、时区、冷却、近远时机因子、未命中累积加成及上限。
- 提供试运行、演练与手动真发；真实投递受总开关、目标、忙闲状态和安静时段约束。
- 投递前重新检查最新配置及会话实例，阻止并发重叠、撤销授权或卸载后的迟到投递。
- 开关即时保存、输入失焦保存，失败回滚；刷新会话清单保留草稿。
- 保持原路由及配置数据路径兼容。命中线不是保证概率，真实搭话会使用配置的模型并产生用量。

## 验证

在本目录运行 `npm test`，或在项目根目录运行完整 `npm test`。模拟宿主与后端测试不等于真实 DSH、QQ 或模型服务验收。
