# 大肥鱼内置模块 · 长期记忆

本模块派生自 [Yuuyuko-uu/dsh-fish-memory](https://github.com/Yuuyuko-uu/dsh-fish-memory)，原作者 **Yuuyuko-uu**。RabbitStudio 在原实现上扩展功能并整合进大肥鱼；不代表原作者出品。完整原许可见 [LICENSE](LICENSE)。

本目录随大肥鱼统一构建、安装和更新，不独立发布。使用方法与正式发布状态见 [项目 README](../../README.md)，版本与完整功能清单见 [changelog-v0.7.3.json](../../update/changelog-v0.7.3.json)。

## 功能与边界

- 自动记忆写入、关键词证据召回、带时间的事件与常驻长期事实，按重要度、情绪、激活与半衰期排序。
- 支持全局及会话开关、召回条数 / 字数 / 日配额、自动扩词、同事实更新与去重。
- 记忆库管理集中提供条目搜索、新增、编辑、称呼、整理、档案、回收站、诊断和语义索引；支持导入导出及召回记录溯源。
- QQ 私聊独立、普通群共享、隔离群独立；仅经桥接来源核验的主人私聊可跨授权库召回。模型正文、昵称和自报身份不能授予权限。
- 隔离群设置在 QQ 映射中管理；切换不搬动或删除旧库。旧数据迁移先预览和备份，只处理来源可信条目，原件保留，重复执行不重复导入。
- 可选 Qwen DashScope Embedding 混合召回，支持模型、维度、门槛、候选数、超时和只写密钥；无密钥、缺向量或失败时回退关键词。
- 索引以记忆 JSON 为唯一正文来源，支持补齐、中断续跑和重建；按正文哈希、模型配置与清库代次使过期向量失效。
- 主人跨库召回不跨库写入。查询在可等待的宿主组装阶段准备，缺少能力时明确降级；不把异步向量请求放入同步 text() 回调。
- 路由 `/dsh-fish-memory/*`、配置、记忆库及第三方词典和许可保持兼容。开启语义召回会向配置的模型服务商发送正文和查询，可能产生费用。

## 验证
