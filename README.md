## 工作台与交互

- **统一管理**：集中管理 QQ、记忆、心情、搭话、接口、文件、日志、用量与更新。
- **状态总览**：查看 QQ 连接、记忆库、心情与主动搭话状态，直接进入对应功能。
- **明暗主题**：跟随 DSH 外观，页面、弹窗与挂饰使用一致配色。
- **自适应布局**：适配宽屏与窄屏，长列表和弹窗内容独立滚动。
- **即时保存**：开关与选择即时生效，文本和数字失焦保存，失败时保留输入或恢复状态。
- **操作反馈**：提供说明、确认弹窗、进度和通知，支持键盘操作与减少动态效果。

## QQ 互通

- **双向对话**：连接 NapCat、SnowLuma 等 OneBot 后端，互通 QQ 私聊、群聊与 DSH 会话。
- **独立会话**：为不同私聊和群聊配置独立绑定、称呼、角色与收发开关。
- **工作区绑定**：管理会话归属，创建或恢复绑定会话及所需工具。
- **启动检查**：开启前检查主人身份、后端、映射、会话和模型配置。
- **接收策略**：支持消息合并、点名接听、连续接听、回复概率、冷却和离线补投。
- **发送策略**：支持唤醒限制、标记范围、来源署名、长回复拆段与按句发送。
- **权限控制**：设置唯一主人、回复门槛与逐会话沙箱权限，沿用宿主审批。
- **输出保护**：拦截异常重复、超长思考及转录泄漏，保留已成功的工具结果并限次恢复。

## 图片、文件与语音

- **图片收发**：接收 QQ 图片，转发会话生成的图片附件与 Markdown 图片。
- **文件收发**：接收私聊和群文件，发送会话文件，校验数量、大小与下载完整性。
- **事件接收**：处理文件上传、离线文件和戳一戳等后端事件。
- **语音转写**：将收到的语音转换为文字，支持识别环境、模型、命令和超时配置。
- **独立归档**：分别控制图片与文件的额外存储，归档失败不阻断消息接收。

## QQ 账号与空间

- **账号资料**：按授权由可信主人修改昵称、签名和头像。
- **申请审批**：接收好友申请与群邀请，交给主人按编号确认或拒绝。
- **跨群查询**：主人可定位授权群，按日期分页读取聊天记录，并查看来源与覆盖缺口。
- **向群代发**：主人可从可信私聊向指定授权群发送文字，核验回执并防止重复投递。
- **空间图文**：发布文字与配图，配置可见范围及定时发布提醒。
- **动态浏览**：查看好友动态、说说详情与评论，配置巡检和点赞；不提供发表评论工具。

## QQ 聊天记录导入

- **记录来源**：文件支持 OneBot JSON（UTF-8）和 QQ 官方 TXT（UTF-8 / GB18030），不设文件大小或文件消息条数上限；文件流式上传、分批排序并分段存盘，分析时只读取当前段。保留按日期读取 OneBot 后端历史，不支持 QCE 等其他导出格式。OneBot JSON 是明文，无需备份密码，导出账号可与当前后端账号不同。
- **加密备份**：QQ NT 官方 `.bak` 可包含 ZIP 容器、1024 字节 QQ 私有头与 SQLCipher 加密数据库，未设置备份密码也可能有账号级加密。当前不能直接导入此类备份，需要原导出账号的数据库解密密钥；其他账号的后端不能替代。选择 `.bak` 会明确提示，不会将大文件按文本读取或创建空任务。
- **按日期读取**：后端选择开始、结束日期，按北京时间筛选且包含结束当天，自动翻页至开始日期之前。OneBot JSON 是接口消息的文件副本，同一账号与同一可见范围下，直接读取后端可取得相同消息；不代表其他账号或 QQ 云端全量历史。达到读取保护上限时会提示区间可能未读完。
- **导入列表**：文件与后端读取统一通过“确认”进入列表，按创建时间倒序显示所有导入记录及完成状态；开始、暂停和继续分析均在列表操作。确认上传不会调用模型，文件越大、消息内容越多，整理记忆时通常消耗更多 Token。
- **分段整理**：按时间分段处理，使用摘要衔接上下文，保留多人发言与附件标记。
- **断点续传**：支持暂停、恢复和失败重试，未确认的内容不会推进进度。
- **定向入库**：固定写入目标记忆库，绑定或隔离变化时阻止旧任务继续写入。

### 导出 OneBot JSON

页面底部提供可展开的导出说明。OneBot 没有统一导出按钮，在持有所需记录的 NapCat / SnowLuma 后端调用历史接口，将成功响应保存为 UTF-8 JSON。例如导出一页群记录：

```sh
curl -X POST http://127.0.0.1:3000/get_group_msg_history \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer 你的令牌' \
  -d '{"group_id":123456789,"count":100}' -o qq-history.json
```

换成自己的地址、令牌和群号；未启用鉴权时省略 Authorization。私聊改用 `get_friend_msg_history`，并将 `group_id` 改为 `user_id`。每次响应只是一页；更多记录按后端的分页游标继续请求，再把各页 `data.messages` 合并成一个消息数组保存，不能直接拼接完整响应。

## 共享表情包

- **素材共享**：私聊与群聊共同使用表情库，支持关键词搜索和分页浏览。
- **素材导入**：支持单张与批量导入、原图预览、标签筛选、编辑和删除。
- **自动整理**：生成名称、标签、场景与分类，保留人工标签，失败后可单张重试。
- **语境发送**：结合当前聊天与回复选择合适表情，遵守发送权限和冷却。
- **自动收藏**：按需收藏实时表情与 GIF，群聊收藏可单独控制。
- **原图保留**：保留 GIF 等原始文件，校验容量，迁移时备份并避免覆盖冲突。

## 长期记忆与语义召回

- **自动记忆**：记录带时间的事件与长期事实，按会话或工作区管理。
- **按需召回**：结合关键词证据、重要度、情绪、激活与遗忘衰减筛选记忆。
- **语义检索**：可选 Qwen Embedding 混合召回，支持门槛、候选数、模型与维度设置。
- **来源隔离**：私聊独立、普通群共享、指定群隔离，主人仅能跨授权范围召回。
- **条目管理**：搜索、新增、编辑、整理、导入导出，以及回收站恢复和彻底清理。
- **档案整理**：从档案提炼候选记忆，管理称呼、事实键、重复合并与日期修复。
- **索引维护**：补齐、暂停续跑或重建向量索引，缺失、超时或失败时回退关键词。
- **诊断迁移**：查看召回依据与原库，预览并备份迁移可信旧数据；QQ 库保持隔离。

## 心情与挂饰

- **心情判断**：维护心情数值与七维情绪，配置判断模型、基线、下限和衰减。
- **范围绑定**：跟随 QQ 记忆库归属，也可使用自定义会话或工作区范围。
- **上下文注入**：选择关闭、心情标签或事件式注入，控制可信度与每日额度。
- **变化记录**：按日期或全部查看心情变化、时间与原因。
- **悬浮挂饰**：支持拖动、缩放、透明度调整，以及卡片展开和收起。
- **卡片内容**：可显示今日心情、今日开销或绑定范围内的随机记忆。
- **形象定制**：五档心情分别配置全身像与半身像，上传后实时同步，支持恢复默认与图片去重。

## 主动搭话

- **主动问候**：按设定时机发起对话，复用目标会话的人格、历史、工具与记忆。
- **时段设置**：配置安静时段、时区、峰谷命中线和冷却。
- **时机调节**：设置近远因子、未命中加成与上限。
- **目标选择**：限定在绑定工作区内的有效会话。
- **试运行与演练**：提供模拟检查和手动真发，投递前重新核验配置与会话状态。

## 开放平台

- **插件接入**：连接同一 DSH 内的原生插件，或配置 HTTP JSON 接口。
- **接口管理**：同一提供方可维护多个接口、参数、示例与认证信息。
- **会话授权**：分别控制接入开关、会话权限与提供方隔离，撤销后及时复核调用。
- **文档与测试**：查看字段说明、OpenAPI 文档，执行接口测试并查看结果。
- **内置能力**：提供 DeepSeek 账户余额、大肥鱼技能库和吃大米饭只读查询。

## 文件、用量与运行日志

- **文件管理**：预览、下载和删除 QQ 图片、文件与表情素材，打开本地存储目录。
- **访问边界**：按可信来源和记忆库权限控制归档访问，删除归档不影响会话附件。
- **用量统计**：查看今日、累计和逐会话 Token、RAG 用量、缓存命中率与估算费用。
- **图表展示**：通过趋势图、活动热力图与悬浮明细查看用量变化。
- **鱼粮提醒**：设置每日费用上限与低余额提醒，达到日上限时自动关闭 QQ 总开关。
- **运行诊断**：自动刷新 QQ 桥日志，展示操作进度、错误原因与重试状态。

## 更新与更新日志

整合版更新日志统一保存在 [update/](update/)，按版本维护固定格式的 JSON，只记录该版本的新增、优化、修复与重要变化；没有变化的功能分类不展示。

- **渠道选择**：支持 npm 国内镜像、GitHub 正式仓库和鉴权私有内测。
- **后台检查**：启动、定期及返回窗口时检查，发现更新后显示侧栏圆点和立即更新按钮。
- **一步更新**：直接安装最新目标，保留来源、版本、完整性与串行校验。
- **安装后日志**：更新成功并重载后弹出随包日志，支持手动查看、分类浏览、历史选择与关闭去重。
- **结果反馈**：展示安装进度，成功或失败时切换对应贴纸。

## 开发与维护

运行环境：Node.js 22+、DSH 0.2.1-rc.2+，QQ 互通另需已配置的 OneBot 后端。当前 0.7.x 为内测阶段，正式发布以仓库发布记录为准。

获取源码后，使用 Node.js 22.13+ 或 24+ 执行 `npm ci --ignore-scripts` 和 `npm run check`；通过 `npm run build` 生成随包客户端。开发安装请在独立 DSH 测试环境中使用其插件管理器的本地包入口，不覆盖日常账号数据。

贡献流程、代码规范、目录说明及合成测试要求见 [CONTRIBUTING.md](CONTRIBUTING.md)，正式发布步骤见 [发布准备](docs/release-preparation.md)。`local/` 用于私有材料，普通测试和必要文档继续公开；npm 安装包只包含显式列出的运行文件。
